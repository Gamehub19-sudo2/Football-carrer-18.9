# Football Manager 2.8 — Formacao e Mercado

- Formacao titular 4-3-3 com 11 vagas: 1 goleiro, 2 zagueiros, 1 lateral esquerdo, 1 lateral direito, 2 meio-campistas, 1 volante, 1 atacante e 2 pontas.
- Os nomes aparecem sobre o campo e cada jogador contratado ocupa uma vaga de sua posicao.
- Limite de 11 contratacoes no elenco titular; jogadores sem posicao compativel ficam indisponiveis no mercado.
- O jogo salva o progresso localmente no navegador.

Publique `index.html` e `README.md` na raiz do GitHub Pages para jogar.
